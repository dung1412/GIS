📤 NHẬP BẢN ĐỒ (SHAPEFILE / MAPINFO / GEOJSON)

Hỗ trợ tệp .ZIP (chứa Shapefile hoặc MapInfo TAB/MIF), tệp .MIF, .GeoJSON hoặc .KML.

🗺️
Kéo thả file KML (.kml, .kmz), MBTiles (.mbtiles), Shapefile / MapInfo (.zip) hoặc .GeoJSON vào đây
Hoặc bấm để duyệt file từ máy tính của bạn
📁 Hướng dẫn nạp file bản đồ:
• Google Earth KML / KMZ: Tải trực tiếp file .kml hoặc .kmz (tự động nhận diện ranh giới và thuộc tính).
• Bản đồ MBTiles: Tải file gạch ngoại tuyến .mbtiles (hỗ trợ raster PNG/JPG/WebP và vector PBF).
• MapInfo TAB: Nén các file .tab, .dat, .map, .id thành 1 file .ZIP.
• MapInfo MIF: Nén .mif và .mid thành file .ZIP (hoặc tải trực tiếp file .mif).
• Shapefile: Nén đủ .shp, .dbf, .shx, .prj thành 1 file .ZIP.
• Hệ thống tự động chuyển đổi hệ tọa độ VN-2000 và giải mã font tiếng Việt TCVN3 (.VnTime) / VNI sang Unicode.

🔤 Chuyển Đổi Mã Font Chữ (TCVN3 ⇄ Unicode)

Khắc phục triệt để lỗi nhảy font trên bản đồ lâm nghiệp, sổ đỏ và hồ sơ địa chính cũ dùng bảng mã TCVN3 / ABC (.VNTime, .VNAvant) sang Unicode (UTF-8) chuẩn quốc tế và ngược lại.

Chiều chuyển đổi: TCVN3 (.VNTime / ABC) ➔ Unicode (UTF-8)
